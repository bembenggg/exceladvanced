Sesi 1: Power Query ETL & Data Sanitization

Pemahaman Konsep Dasar ETL (Extract, Transform, Load)

Sebelum masuk ke praktik, peserta wajib memahami paradigma arsitektur data ETL yang menjadi standar pembersihan Big Data di divisi Human Capital:

1. EXTRACT

Proses penarikan atau pengambilan data mentah dari berbagai sumber terpisah (seperti file mesin absensi sidik jari dan data induk HR) untuk dikumpulkan ke staging area Power Query.

2. TRANSFORM

Proses pembersihan dan manipulasi data. Di tahap ini, spasi liar dihapus (Trim), tabel absensi dihubungkan ke data master (Merge), dan baris data lintas bulan ditumpuk (Append).

3. LOAD

Proses pemuatan data yang telah steril, rapi, dan matang kembali ke media akhir (Worksheet Excel) untuk siap digunakan sebagai fondasi Pivot Table atau pelaporan eksekutif.

Konsep Sanitasi Data: Kasus Spasi Liar (Trim)

Salah satu penyebab utama kegagalan relasi data (Error #N/A atau kegagalan *Merge*) adalah keberadaan spasi tak terlihat di awal atau akhir teks. Karakter spasi dianggap karakter valid oleh sistem, sehingga teks dengan spasi tidak akan pernah cocok dengan teks master yang bersih.

Sebelum Proses Trim (Data Rusak)

"   Ahmad Fauzi   "

Sistem mendeteksi panjang string karakter berbeda dan gagal mencocokkan ID.

Setelah Proses Trim (Steril)

"Ahmad Fauzi"

Seluruh spasi luar dipangkas otomatis. Data siap digabungkan dengan aman.

Aktivitas Pembersihan & Kombinasi Data

  1. Trim & Clean: Klik kanan header kolom Nama_Karyawan di Editor Power Query > Transform > Trim untuk menyingkirkan spasi luar tak terlihat secara otomatis. Lakukan juga fungsi Clean untuk menghapus objek baris baru tak kasat mata.
  2. Format Teks Uniform: Klik kanan kolom Status_Kehadiran > Transform > Capitalize Each Word agar semua teks seragam diawali huruf kapital (contoh: "Hadir").
  3. Merge Queries (Relasi Kolom): Menghubungkan tabel Absensi_Juni_Mentah dengan Master_Karyawan berdasarkan parameter kesamaan kolom Emp_ID.
  4. Append Queries (Konsolidasi Vertikal): Menyatukan baris data bulan Juni dan data baru bulan Juli secara bertumpuk agar menjadi database tunggal.

Sesi 2: Otomatisasi VBA Macro & Validasi Data

Tutorial Cara Merekam Macro (Record Macro) untuk Pemula

Merekam macro adalah metode paling dasar dan efektif untuk mengotomatiskan tugas berulang tanpa harus menulis skrip kode dari awal. Excel akan melacak dan merekam setiap klik, ketikan, dan format yang Anda lakukan, lalu mengubahnya menjadi kode VBA secara otomatis.

Alur Kerja Perekaman Macro:
  1. Aktifkan Tab Developer pada Ribbon menu Excel Anda. (Jika belum muncul, aktifkan melalui File > Options > Customize Ribbon).
  2. Klik tombol Record Macro pada grup *Code*.
  3. Beri nama macro Anda (tanpa spasi, contoh: FormatTabelOtomatis) dan tentukan *shortcut* opsional.
  4. Lakukan aktivitas manual di lembar kerja Anda (misal: menebalkan header, memberi warna background tabel, merubah format mata uang).
  5. Jika aktivitas selesai, kembali ke Tab Developer lalu klik Stop Recording.

1. Skrip Pembuat PDF Otomatis

Setelah dasar makro dipahami, berikut adalah skrip tingkat lanjut untuk mengekspor data laporan profil karyawan menjadi dokumen PDF siap cetak hanya dengan satu kali klik tombol:

VBA Module Script
Sub CetakLaporanKaryawan()
    Dim IDKaryawan As String, PathPenyimpanan As String
    IDKaryawan = Sheets("Dashboard").Range("H2").Value
    PathPenyimpanan = Application.ActiveWorkbook.Path & "\Laporan_" & IDKaryawan & ".pdf"
    If IDKaryawan = "" Then
        MsgBox "ID Karyawan di H2 Kosong!", vbExclamation: Exit Sub
    End If
    Sheets("Profil_Karyawan").ExportAsFixedFormat Type:=xlTypePDF, Filename:=PathPenyimpanan
    MsgBox "Laporan PDF Berbuat Berhasil!", vbInformation
End Sub

2. Skrip Validasi Intersept Nilai Batas

Skrip Event Sheet di bawah ini mendeteksi ketikan input user secara *real-time*. Jika ada pengisian skor kinerja di luar jangkauan angka 1-100, entri data ditolak langsung:

VBA Sheet Event
Private Sub Worksheet_Change(ByVal Target As Range)
    If Not Intersect(Target, Range("E2:E100")) Is Nothing Then
        If Target.Value < 1 Or Target.Value > 100 Then
            Application.EnableEvents = False
            MsgBox "Skor Kinerja Harus Berada di Angka Rentang 1-100!", vbCritical
            Target.Value = ""
            Application.EnableEvents = True
        End If
    End If
End Sub

Sesi 3: Dynamic Executive Dashboard Design

Definisi Teoretis Executive Dashboard & Visual Chart

Executive Dashboard adalah antarmuka visual terintegrasi yang merangkum berbagai indikator kinerja utama (KPI) suatu organisasi ke dalam satu layar monitor tunggal yang interaktif. Dashboard ini berfungsi sebagai *Single Source of Truth* (SSOT) yang mempermudah jajaran manajemen mengambil keputusan bisnis secara cepat, presisi, dan berbasis data (*data-driven decision making*).

Dalam mendesain dashboard profesional, terdapat aturan esensial yang disebut Data-to-Ink Ratio. Prinsip ini menyatakan bahwa setiap elemen tinta atau piksel grafis di layar harus berfokus penuh untuk menyampaikan informasi data kritikal. Singkirkan dekorasi visual, warna latar belakang kontras yang tidak perlu, efek 3D, atau garis tepi yang tebal karena berisiko mendistorsi fokus analisis data penting manajemen.

Katalog Eksplanasi Komponen Grafik Visual Excel

Seorang analis HR wajib memahami peruntukan unik setiap jenis grafik agar informasi tidak terdistorsi atau salah diinterpretasikan:

Column & Bar Chart (Batang)

Definisi: Grafik yang menyajikan data menggunakan batang persegi panjang.
Fungsi: Sangat ideal untuk membandingkan perbedaan nilai nominal antarkategori berbeda (contoh: Membandingkan total jumlah karyawan atau rata-rata skor performa per direktorat).

Pie Chart (Lingkaran / Pai)

Definisi: Grafik lingkaran yang dibagi menjadi potongan-potongan proporsional berskala.
Fungsi: Menunjukkan komposisi atau kontribusi persentase terhadap total keseluruhan tunggal (100%). Hanya efektif digunakan jika jumlah kategori sedikit, maksimal 3-5 kategori (contoh: Rasio persentase jenis kelamin karyawan).

Donut Chart

Definisi: Variasi dari Pie Chart yang memiliki lubang kosong di pusat tengahnya.
Fungsi: Memiliki tujuan yang sama dengan Pie Chart (porsi kontribusi), namun ruang kosong di tengah dapat diisi teks informasi ringkasan tambahan, sehingga menghemat ruang estetika layar dashboard.

Line Chart (Grafik Garis)

Definisi: Grafik berbentuk rangkaian titik data berkelanjutan yang dihubungkan oleh garis lurus.
Fungsi: Menampilkan perkembangan tren, fluktuasi, atau pola pergerakan data dari waktu ke waktu secara berkesinambungan (contoh: Tren tingkat keterlambatan karyawan dari bulan Januari hingga Desember).

Combo Chart (Grafik Gabungan Berlapis)

Definisi: Penggabungan dua jenis grafik berbeda (misalnya grafik batang dipadu dengan grafik garis) ke dalam satu diagram tunggal yang didukung sumbu sekunder (*Secondary Axis*).
Fungsi: Digunakan untuk membandingkan dua tipe set data dengan skala satuan ukur yang berbeda secara bersamaan (contoh: Batang menampilkan *Jumlah Absensi Karyawan* sedangkan Garis menampilkan *Persentase Efektivitas Jam Kerja*).
