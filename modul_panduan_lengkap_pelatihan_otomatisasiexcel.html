Jam 1: Power Query ETL (Extract, Transform, Load)

Di modul ini, kita akan melatih kemampuan mengonsolidasikan data absensi dan data induk karyawan secara dinamis tanpa mengetik formula tunggal.

Alur Logika Power Query ETL

Aktivitas Pembersihan (Sanitization)

  1. Memasukkan Data ke Query Editor:

    Klik di sel manapun dalam tabel Absensi_Mentah. Pilih menu Data > From Sheet / From Table/Range. Jika muncul dialog konfirmasi tabel, centang "My table has headers" and klik OK.

  2. Melakukan Trim Kolom Nama:

    Di jendela editor Power Query, klik kanan pada header kolom Nama_Karyawan. Pilih Transform > Trim. Langkah ini akan menghapus semua spasi berlebih di awal maupun di akhir penulisan secara otomatis.

  4. Menggabungkan (Merge) dengan Master Karyawan:

    Pada tab Home di jendela Power Query, klik tombol dropdown Merge Queries. Pada kotak pilihan bawah, pilih tabel Master_Karyawan. Hubungkan relasi menggunakan kolom Emp_ID di kedua tabel.

    Geser ke ujung kanan hingga menemukan kolom baru bernama Master_Karyawan. Klik ikon anak panah ganda berlawanan arah di kanan header. Uncheck semua kolom kecuali Direktorat dan Perf_Score_2025. Hilangkan centang pada opsi "Use original column name as prefix", lalu klik OK.

  6. Menyimpan & Memuat Data:

    Di bagian kiri atas menu Home, klik tombol Close & Load. Data bersih hasil kalkulasi engine Power Query akan otomatis diekspor ke tab sheet baru. Ubah nama tab tersebut menjadi Data_Absensi_Clean.

Mengapa Power Query Lebih Baik dari VLOOKUP? Pencocokan data dengan Power Query dijalankan langsung oleh mesin komputasi (engine) memori. Excel Anda tidak akan mengalami "freeze/loading berat" seperti saat menghitung ribuan baris baris sel formula VLOOKUP konvensional.

Latihan Dasar: Merekam Rutinitas (Macro Recorder)

Sebagai langkah awal memahami logika pemrograman Excel VBA, kita akan merekam langkah manual berupa pemberian format tabel otomatis (memberikan warna kepala tabel dan menebalkan teks), lalu menjalankannya kembali secara otomatis dengan satu tombol.

Bagaimana Cara Kerja Macro Recorder? Ketika perekaman dimulai, Excel akan menerjemahkan setiap klik mouse, seleksi sel, dan pemformatan warna yang Anda lakukan di layar menjadi baris kode pemrograman VBA secara real-time di latar belakang.
  1. Mulai Perekaman (Record Macro):

    Buka tab Developer di Excel Anda, lalu klik tombol Record Macro di kelompok menu Code. Dialog pengaturan nama macro akan segera muncul.

    Dialog Box: Record Macro
    Macro name:
    Shortcut key: Ctrl + Shift +
    Store macro in:
  2. Melakukan Aksi Rutinitas:

    Setelah mengklik OK pada dialog rekam, lakukan aktivitas pemformatan berikut pada data mentah:

    1. Seleksi baris header tabel A4 sampai F4 di lembar kerja Anda.

    2. Ubah warna latar belakang (Fill Color) menjadi biru gelap (Navy Blue).

    3. Ubah warna teks font menjadi putih, berikan gaya cetak tebal (Bold), dan rata tengah (Center).

  3. Menghentikan Perekaman:

    Jika semua aksi pemformatan selesai, kembali ke tab Developer, lalu klik tombol Stop Recording (tombol ini menggantikan posisi tombol Record Macro sebelumnya).

  4. Melihat Hasil Terjemahan Kode:

    Tekan ALT + F11 untuk masuk ke editor VBA, dan periksa folder Modules -> Module1. Anda akan menemukan kode otomatis hasil terjemahan rekaman seperti berikut: 

    ' Kode di bawah ini adalah HASIL GENERATE OTOMATIS dari rekaman Anda
Sub FormatHeaderOtomatis()
    Range("A4:F4").Select
    With Selection.Interior
        .Pattern = xlSolid
        .Color = RGB(15, 23, 42) ' Warna Latar Biru Gelap
    End With
    With Selection.Font
        .Bold = True
        .Color = RGB(255, 255, 255) ' Warna Font Putih
    End With
    With Selection
        .HorizontalAlignment = xlCenter
    End With
    Range("A1").Select ' Kembali fokus ke sel utama
End Sub
Saran Pembelajaran Instruktur: Ajari peserta untuk selalu mencoba fitur Macro Recorder terlebih dahulu apabila mereka lupa nama properti visual di dalam kode VBA (seperti cara mengganti warna, ukuran font, atau lebar sel). Cukup rekam aksinya, lalu pelajari kodenya!

Kasus 1: Auto-PDF & Laporan Slip Individual Satu Klik

Membantu manajer HC memilah log kehadiran dari satu karyawan tertentu, memindahkannya ke sheet tersendiri, dan merapikannya secara instan. 

Sub BuatRekapIndividu()
    Dim wsAsli As Worksheet
    Dim wsBaru As Worksheet
    Dim empID As String
    Dim barisAkhir As Long, barisBaru As Long
    Dim i As Long
    
    ' Mengaktifkan penanganan eror sederhana
    On Error GoTo ErrorHandler
    
    ' Ambil ID Karyawan dari Input Box dinamis agar interaktif
    empID = InputBox("Masukkan ID Karyawan yang ingin diekstrak (Contoh: HC01):", "Ekstraktor Data HCIS")
    
    If Trim(empID) = "" Then
        MsgBox "Proses dibatalkan. ID Karyawan tidak boleh kosong!", vbExclamation, "Peringatan"
        Exit Sub
    End If
    
    Set wsAsli = Sheets("Absensi_Mentah")
    
    ' Memeriksa apakah Sheet Rekap lama dengan ID tersebut sudah ada, jika ada dihapus dahulu
    Application.DisplayAlerts = False
    On Error Resume Next
    Sheets("Rekap_" & empID).Delete
    On Error GoTo ErrorHandler
    Application.DisplayAlerts = True
    
    ' Membuat Sheet Baru di urutan paling belakang
    Set wsBaru = Worksheets.Add(After:=Sheets(Sheets.Count))
    wsBaru.Name = "Rekap_" & empID
    
    ' Desain Tata Letak Header Laporan
    With wsBaru
        .Range("A1").Value = "LAPORAN KEHADIRAN INDIVIDU"
        .Range("A1").Font.Size = 16
        .Range("A1").Font.Bold = True
        .Range("A2").Value = "ID Karyawan Target: " & empID
        .Range("A2").Font.Italic = True
        
        .Range("A4:F4").Value = Array("Tanggal", "Emp_ID", "Nama", "Jam Masuk", "Jam Pulang", "Status")
        .Range("A4:F4").Font.Bold = True
        .Range("A4:F4").Interior.Color = RGB(15, 23, 42)
        .Range("A4:F4").Font.Color = RGB(255, 255, 255)
    End With
    
    barisAkhir = wsAsli.Cells(wsAsli.Rows.Count, "B").End(xlUp).Row
    barisBaru = 5
    
    ' Looping Pemindaian Data
    For i = 2 To barisAkhir
        If Trim(wsAsli.Cells(i, 2).Value) = empID Then
            wsBaru.Cells(barisBaru, 1).Value = wsAsli.Cells(i, 1).Value
            wsBaru.Cells(barisBaru, 2).Value = wsAsli.Cells(i, 2).Value
            wsBaru.Cells(barisBaru, 3).Value = Trim(wsAsli.Cells(i, 3).Value)
            wsBaru.Cells(barisBaru, 4).Value = wsAsli.Cells(i, 4).Value
            wsBaru.Cells(barisBaru, 5).Value = wsAsli.Cells(i, 5).Value
            wsBaru.Cells(barisBaru, 6).Value = wsAsli.Cells(i, 6).Value
            barisBaru = barisBaru + 1
        End If
    Next i
    
    ' Jika data tidak ditemukan
    If barisBaru = 5 Then
        Application.DisplayAlerts = False
        wsBaru.Delete
        Application.DisplayAlerts = True
        MsgBox "Data dengan ID " & empID & " tidak ditemukan!", vbExclamation, "Pencarian Gagal"
        Exit Sub
    End If
    
    wsBaru.Columns("A:F").AutoFit
    MsgBox "Laporan individual untuk ID " & empID & " berhasil dipisahkan!", vbInformation, "Sukses"
    Exit Sub

ErrorHandler:
    MsgBox "Terjadi kesalahan sistem: " & Err.Description, vbCritical, "Error Handler"
End Sub

Kasus 2: Validasi Batas Penilaian Performance Score Karyawan

Menolak input di luar skala perusahaan (0 - 100) dan mengembalikan sel ke kondisi semula sebelum kesalahan entri terjadi guna menjaga validitas pangkalan data. 

Private Sub Worksheet_Change(ByVal Target As Range)
    Dim cellTarget As Range
    Dim batasMonitor As Range
    
    ' Mendefinisikan kolom E (Performance Score) sebagai target pengawasan
    Set batasMonitor = Me.Range("E2:E100")
    
    ' Periksa apakah ada perubahan di area batasMonitor
    If Not Intersect(Target, batasMonitor) Is Nothing Then
        ' Mematikan event sementara agar pengisian balik nilai ke sel tidak mentrigger fungsi berulang (infinite loop)
        Application.EnableEvents = False
        
        For Each cellTarget In Intersect(Target, batasMonitor)
            If cellTarget.Value <> "" Then
                ' Memvalidasi apakah input bernilai numerik dan berada di batas aman
                If Not IsNumeric(cellTarget.Value) Or cellTarget.Value < 0 Or cellTarget.Value > 100 Then
                    MsgBox "Pengisian Ditolak!" & vbCrLf & _
                           "Sistem mendeteksi input tidak valid di sel " & cellTarget.Address & vbCrLf & _
                           "Nilai harus berupa angka numerik dengan rentang 0 s.d 100.", vbCritical, "Validasi Entry HCIS"
                    
                    ' Batalkan entri dan kosongkan kembali sel
                    cellTarget.Value = ""
                    cellTarget.Select
                End If
            End If
        Next cellTarget
        
        ' Menghidupkan kembali penanganan Event Listener sistem
        Application.EnableEvents = True
    End If
End Sub
Perhatian Penempatan Kode Kasus 2: Jangan masukkan kode Kasus 2 ke modul standar. Kode ini bersifat Worksheet Event, sehingga wajib disalin di bawah lembar objek lembar kerja bersangkutan, yaitu dengan klik kanan tab sheet Master_Karyawan > pilih View Code.

Langkah-Langkah Pembuatan Dashboard

  1. Membuat Pivot Table Pertama (Komposisi Absensi):

    Klik di dalam tabel Data_Absensi_Clean hasil pengolahan Power Query. Klik menu Insert > PivotTable. Pilih lembar kerja baru untuk penempatan dan beri nama sheet tersebut Dashboard_HCIS.

    Tarik kolom Direktorat ke kotak Rows (Baris), kolom Status_Kehadiran ke kotak Columns (Kolom), and Emp_ID ke area Values (Nilai) (Pastikan diringkas menggunakan rumus aggregasi Count).

  2. Membuat Pivot Table Kedua (Korelasi Kinerja & Ketepatan Waktu):

    Di lembar kerja yang sama (sejajarkan di bawah atau di samping Pivot 1), klik kembali Insert > PivotTable dengan sumber data yang sama.

    Tarik kolom Nama ke kotak Rows, kolom Perf_Score_2025 ke kotak Values (Ganti summary value field-nya dari Sum menjadi Average). Tarik kembali kolom Status_Kehadiran ke area Values (Setting aggregasi sebagai Count, lalu berikan filter pada Pivot Row untuk menampilkan tipe status "Terlambat" saja).

  3. Pembuatan Pivot Chart 1 (Stacked Column Chart):

    Aktifkan Pivot Table pertama, klik PivotTable Analyze > PivotChart. Pilih kategori **Stacked Column Chart (Batang Bertumpuk)**. Berikan judul: Proporsi Kedisiplinan Kehadiran per Direktorat.

  4. Pembuatan Pivot Chart 2 (Combo Chart Korelasi):

    Aktifkan Pivot Table kedua, buka menu PivotChart Analyze > PivotChart. Pilih kategori Combo (Kombinasi) di bagian bawah. Pilih Perf_Score_2025 sebagai Clustered Column, dan Count of Status_Kehadiran sebagai Line. Centang kotak Secondary Axis pada tipe line agar skala angka performa (skala 100) dan jumlah terlambat (skala satuan) memiliki sumbu ukur masing-masing. Berikan judul: Tren Korelasi Performa vs Keterlambatan Individu.

  5. Mengintegrasikan Slicer Interaktif:

    Klik salah satu grafik. Pilih menu PivotChart Analyze > Insert Slicer. Centang bagian Direktorat dan klik OK. Atur posisi kotak slicer di sebelah kiri atau atas grafik agar rapi.

  6. Koneksi Relasi Slicer (Report Connections):

    Klik kanan pada kotak Slicer Direktorat yang baru dibuat, lalu klik Report Connections.... Di dalam jendela pop-up, centang seluruh nama Pivot Table yang ada (baik PivotTable1 maupun PivotTable2). Klik OK.

Definisi Slicer dalam Analisis Data Eksekutif: Slicer berperan sebagai pengendali filter visual yang memangkas beban kerja pembuatan slide statis. Dengan satu Slicer terhubung, Anda tidak perlu lagi menyiapkan satu slide visual terpisah untuk setiap direktorat perusahaan. Cukup klik tombol direktorat target di slicer, dan seluruh komponen visual di dashboard akan bergeser menyaring data secara instan.
